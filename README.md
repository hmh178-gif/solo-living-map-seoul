# 혼삶 안심지도 · 서울

서울시 **1인가구 비율**과 **생활편의시설 분포**를 한 지도에서 탐색하는 인터랙티브 웹 지도입니다.
동네를 검색하면 반경 2km 이내의 편의점 · 코인세탁방 · 안심택배함 · 야간 약국 · 심야버스 정류소를 확인할 수 있습니다.

🔗 **[Live Demo](https://spectacular-muffin-2a39e8.netlify.app/)**

---

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 대상 지역 | 서울시 25개 자치구 |
| 지도 포인트 | **14,288곳** (중복 0) |
| 시설 유형 | 7종 (편의점 · 코인세탁방 · 안심택배함 · 평일 야간 약국 · 토요일 약국 · 일요일 약국 · 심야버스) |
| 기간 | 2026.08 |

초기에는 분석 차트를 함께 제공할 계획이었으나, **실제 활용성을 기준으로 지도 중심 결과물**로 방향을 조정했습니다.

## 2. 핵심 과제 — '24시간 약국'은 왜 쓸 수 없었는가

처음에는 자연스럽게 **24시간 약국**을 야간 인프라 지표로 잡았습니다. 그런데 서울 전체에서 조건을 만족하는 약국이 **단 3곳**이었습니다. 자치구별 비교가 불가능한 수치였습니다.

기준을 버리는 대신 **운영시간 분포를 다시 확인하고 기준을 재설계**했습니다.

> **평일 5일 모두 개·폐점 시간이 기록되어 있고, 5일 전부 22시 이후에 폐점하는 약국**

제외 조건: 평일 운영시간 일부 누락 · 평일 중 휴무 · 일부 요일만 야간 운영 · 개폐점 시간 누락 · 중복 의심 시설

### 재설계 결과

| 구분 | 곳수 |
|---|---|
| 서울 약국 원본 | 5,442 |
| 평일 운영시간 완전 기록 | 5,410 |
| **평일 매일 22시 이후 폐점** | **426** |
| 토요일 17시 이후 운영 | 1,890 |
| 일요일 운영 | 1,483 |
| 토·일 모두 운영 | 1,036 |
| 지도 표시 고유 약국 | 2,346 |

3곳 → 426곳으로, **분석 가능한 지표**가 되었습니다.
약국은 여러 조건을 동시에 만족할 수 있어 속성별 합계와 고유 약국 수는 일치하지 않습니다.

## 4. 데이터 정제

### 코인세탁방 — 신뢰등급 분류

카카오 API 검색 결과에는 일반 세탁소 등 관련성 낮은 시설이 섞여 들어옵니다. 후보에 신뢰등급을 부여해 선별했습니다.

| 등급 | 곳수 | 처리 |
|---|---|---|
| A | 774 | 지도 포함 |
| B | 621 | 지도 포함 |
| C | 314 | 별도 보존 (추후 검토) |
| 제외 | 33 | 삭제 |

C등급을 삭제하지 않고 **보존**한 것은, 판단 기준이 바뀌었을 때 되돌릴 수 있게 하기 위함입니다.

### 편의점 — 공간 분할 수집

카카오 API는 한 번에 반환하는 검색 결과 수가 제한됩니다. **서울을 여러 공간으로 분할**하고, 제한 건수를 초과하는 영역이 없을 때까지 분할 여부를 재확인하는 방식으로 누락을 막았습니다.

### 심야버스 — 경계 밖 정류소 처리

GeoJSON 경계 밖으로 판정된 정류소 6곳을 개별 확인한 결과, 모두 서울 경계 인근의 차고지·정류소였습니다. 삭제하지 않고 **가장 가까운 자치구(은평구)로 재배정**해 1,499곳 전부를 유지했습니다.

## 5. 지도 구현

### 자치구 레이어
- 25개 자치구 GeoJSON 경계 표시
- **1인가구 비율에 따른 색상 단계** (낮음: 밝은 노랑 → 높음: 주황·적색)
- 마우스 오버 시 1인가구 비율 + 시설 현황 표시
- 서울 경계를 벗어나지 않도록 지도 이동·확대 범위 제한

### 시설 레이어
시설별 색상 구분 + 마커 밀집 시 **군집(클러스터) 표시**. 원하는 시설만 선택해 분포 비교가 가능합니다.

| 시설 | 색상 | 시설 | 색상 |
|---|---|---|---|
| 편의점 | 블루 | 토요일 약국 | 로즈 |
| 코인세탁방 | 바이올렛 | 일요일 약국 | 포레스트 그린 |
| 안심택배함 | 골든 옐로 | 심야버스 | 네이비 |
| 평일 야간 약국 | 브릭 레드 | | |

### 동네 검색
동네 · 역 · 주소 검색 → 해당 위치로 이동 → **반경 2km 표시** → 주변 시설 레이어 확인
(서울 밖 검색 결과는 제외)

### 카카오맵 연결
마커 클릭 시 시설명 · 자치구 · 주소 · 상세정보와 함께 **`카카오맵에서 보기`** 버튼 제공.
시설명과 위경도를 이용한 바로가기 형식이라 **별도의 JavaScript API 키 없이** 외부 카카오맵으로 연결됩니다.

## 7. 트러블슈팅

| 문제 | 원인 | 해결 |
|---|---|---|
| 약국 수 불일치 (5,440 vs 5,442) | 이전 정제 결과를 참조하는 데이터프레임 자동 선택 | 최종 원본 5,442곳 기준으로 재계산 → 426곳과 판정 일치 확인 |
| 주말 약국 속성 누락 | 통합 시 주말 운영시간 열이 없는 데이터를 선택 | 운영시간 원본으로 토·일 기준 재계산 후 복구 |
| ZIP 파일을 찾지 못함 | Colab 재업로드 시 `(1)` 접미사가 붙음 | 업로드된 ZIP을 자동 탐색하도록 수정 |
| 지도에 파란 사각형 | GeoJSON이 아닌 **디버그용 이동범위 표시** | 표시 제거, 서울 GeoJSON 실제 범위만 이동 제한에 사용 |
| 카드 색상 바가 모서리 밖으로 돌출 | 둥근 테두리에 내부 요소가 잘리지 않음 | 카드 내부 요소를 테두리에 맞춰 클리핑 |
